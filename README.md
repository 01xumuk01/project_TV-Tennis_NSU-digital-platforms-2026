## Описание проекта 

Командной работой была реализована игра TV-Tennis с механикой, впервые представленной Уильямом Хигинботамом в 1958 году. Механика - есть две ракетки по краям поля, которые могут передвигаться только по вертикали (оси Y) и есть мячик, который эти ракетки должны отбивать. Игра расчитана на одного игрока и робота, алгоритм которого также был разработан командой.
